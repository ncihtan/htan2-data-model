# HTAN Data Model

LinkML data model for the Human Tumor Atlas Network (HTAN). Source YAML schemas
define classes, slots, and enums for each assay module; `make modules-gen` compiles
them into Python dataclasses and JSON schemas.

---

## Repo Structure

```
modules/
  Biospecimen/       Clinical/          CoreFile/
  DigitalPathology/  Imaging/           MultiplexMicroscopy/
  scRNA-seq/         Sequencing/        SpatialOmics/        WES/
    domains/           # Source YAML schemas (edit these)
      *.yaml
    src/htan_*/        # Generated Python dataclasses (do NOT edit)
      datamodel/
JSON_Schemas/          # Generated JSON schemas for Synapse (do NOT edit)
scripts/               # Build + review tooling
tests/                 # pytest test suite
archive/               # Retired schemas — do not review
```

Each module under `modules/` has a `domains/` directory with the source YAML and
a `src/` directory with generated code. Only edit files under `domains/`.

---

## Source vs Generated

| Edit | Generated by |
|---|---|
| `modules/*/domains/*.yaml` | You (source of truth) |
| `modules/*/src/*/datamodel/*.py` | `make modules-gen` |
| `JSON_Schemas/*.json` | `make modules-gen` |

Generated artifacts are produced in a separate downstream PR — never commit them
alongside YAML changes.

## Naming Conventions

- Slot names: `ALL_CAPS_WITH_UNDERSCORES`
- Enum names: `CamelCase`
- Titles: `Title Case`
- Descriptions: sentence case, first word capitalised
- All enum permissible values: alphabetically ordered
- Every slot must have `title` and `description`

---

## Inheritance Pattern

Sequencing modules follow a strict level hierarchy:

```
CoreFileAttributes
  └─ BaseSequencingAttributes             (is_a: CoreFileAttributes)
       └─ BaseSequencingLevel1Attributes   (is_a: BaseSequencingAttributes)
            └─ BaseSequencingLevel2Attributes (is_a: ...Level1Attributes)
                 └─ BaseSequencingLevel3Attributes (is_a: ...Level2Attributes)
                      └─ BulkWESLevel3            (is_a: ...Level3Attributes)
                      └─ scRNALevel3and4          (is_a: ...Level3Attributes)
```

No level may skip its parent (e.g., Level3 directly inheriting BaseSequencingAttributes
is invalid). New assay modules must follow the same pattern.

## Key Commands

```sh
make install          # Install dependencies via Poetry
make modules-gen      # Generate Python dataclasses + JSON schemas for all modules
make modules-test     # Run per-module tests
make test             # Run all tests (pytest)
make format           # Format code with Black
make lint             # Lint
make clean            # Remove build artifacts
```

---

## Testing

```sh
poetry run pytest                       # All tests
poetry run pytest tests/                # Top-level tests only
make modules-test                       # Per-module test suites
```

Test data lives in `tests/test_data/`.
