# Spatial

HTAN Spatial Omics Data Model Schema for Phase 2 - All Levels

The HTAN Spatial Omics module provides a comprehensive data model for spatial omics assays. This module defines schemas for multiple data levels:

- **Level 1**: Raw data bundle (optional)
- **Level 3**: Processed bundle (required)
- **Level 4**: Interoperable file (optional)
- **Panel**: Panel information
