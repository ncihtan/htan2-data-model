# WES

HTAN Whole Exome Sequencing Data Model Schema

The HTAN WES module provides a comprehensive data model for bulk whole exome sequencing data. This module defines schemas for three data levels:

- **Level 1**: Raw sequencing files and metadata
- **Level 2**: Aligned files and alignment QC
- **Level 3**: Called variants
