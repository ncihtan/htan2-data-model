# MultiplexMicroscopy

HTAN Multiplex Microscopy Data Model Schema for Phase 2 - All Levels

The HTAN Multiplex Microscopy module provides a comprehensive data model for multiplexed tissue imaging assays. This module defines schemas for three data levels:

- **Level 2**: Imaging data with channel metadata
- **Level 3**: Segmentation masks
- **Level 4**: Cell-by-feature tables

## Levels

- :doc:`Level 2 <multiplexmicroscopy/level-2>` - Imaging data with channel metadata
- :doc:`Level 3 <multiplexmicroscopy/level-3>` - Segmentation masks
- :doc:`Level 4 <multiplexmicroscopy/level-4>` - Cell-by-feature tables
