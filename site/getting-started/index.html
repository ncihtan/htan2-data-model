    Getting Started

    Welcome to the HTAN Phase 2 Data Model! This guide will help you get started with understanding and using the data model.

    What is HTAN2?

    The HTAN Phase 2 Data Model is a comprehensive, modular data model for standardizing cancer research data. It's built using LinkML, which allows us to generate Python classes, JSON schemas, and other formats from a single source of truth.

    Key Concepts

    Module Types

    The HTAN2 data model has two main types of modules:

    1. Record-Based Modules: Represent clinical and biospecimen data as records
    2. Clinical

    3. Biospecimen

    4. File-Based Modules: Represent data files organized in hierarchical levels

    5. Sequencing modules (WES, scRNA-seq)
    6. Imaging modules (Digital Pathology, Multiplex Microscopy)
    7. Spatial Omics

    Data Hierarchy

    Participant (HTAN_PARTICIPANT_ID)
├── Biospecimen (HTAN_BIOSPECIMEN_ID)
│   └── Level 1 Data (HTAN_DATA_FILE_ID)
│       └── Level 2 Data (HTAN_DATA_FILE_ID)
│           └── Level 3 Data (HTAN_DATA_FILE_ID)

    HTAN Identifiers

    All HTAN entities use standardized identifier patterns:

    • HTAN_PARTICIPANT_ID: HTA200_2 (no suffix)
    • HTAN_BIOSPECIMEN_ID: HTA200_2_B7001 (B suffix)
    • HTAN_DATA_FILE_ID: HTA200_2_D36667 (D suffix)
    • HTAN_PARENT_ID: References parent entity (B or D suffix)

    Installation

    Prerequisites

    • Python 3.11+
    • Poetry (for dependency management)

    Setup

    # Clone the repository
git clone https://github.com/ncihtan/htan2-data-model.git
cd htan2-data-model

# Install dependencies
poetry install

# Generate schema classes for all modules
make modules-gen

# Run tests
make test

    Using the Data Model

    Python Usage

    from htan_clinical import ClinicalDemographics
from htan_biospecimen import BiospecimenData
from htan_wes import BulkWESLevel1

# Create a clinical record
demographics = ClinicalDemographics(
    HTAN_PARTICIPANT_ID="HTA200_2",
    SEX="Male",
    RACE="White"
)

# Create a biospecimen record
biospecimen = BiospecimenData(
    HTAN_BIOSPECIMEN_ID="HTA200_2_B7001",
    HTAN_PARENT_ID="HTA200_2",
    BIOSPECIMEN_TYPE="Tissue",
    ACQUISITION_METHOD_TYPE="Surgical Resection"
)

# Create a WES Level 1 file record
wes_level1 = BulkWESLevel1(
    HTAN_DATA_FILE_ID="HTA200_2_D36667",
    HTAN_PARENT_ID="HTA200_2_B7001",
    FILENAME="sample_R1.fastq.gz",
    FILE_FORMAT="fastq.gz",
    LIBRARY_LAYOUT="Paired-end",
    SEQUENCING_PLATFORM="ILLUMINA",
    READ_LENGTH=150
)

    Validation

    # Validate records
try:
    demographics.validate()
    biospecimen.validate()
    wes_level1.validate()
    print("✅ All records are valid")
except ValidationError as e:
    print(f"❌ Validation error: {e}")
